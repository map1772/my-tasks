# Мои задачи

Адаптивное todo-приложение на React. Задачи сохраняются в браузере и не требуют регистрации или сервера.

## Демо

- [Базовая версия](https://my-tasks-map1772.vercel.app)
- [Версия со стеклянным dashboard и папками](https://my-tasks-folders-map1772.vercel.app)

## Возможности

- добавление задачи кнопкой или клавишей Enter;
- выполнение, возврат в работу и удаление;
- редактирование названия, описания и срока;
- автоматический расчёт прогресса;
- сохранение всех изменений в `localStorage`;
- полноэкранный detail-view задачи;
- адаптация для компьютеров и телефонов;
- клавиатурное управление и возврат фокуса;
- поддержка `prefers-reduced-motion`.

## Стек

- React 19;
- TypeScript;
- Vite;
- Vitest и React Testing Library;
- Playwright;
- CSS без компонентного UI-фреймворка.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm run test
npm run lint
npm run build
npm run test:e2e
```

## Хранение данных

Задачи хранятся в `localStorage` под ключом `my-tasks:v1`. Приложение не отправляет пользовательские данные на сервер. Старые задачи без описания и срока продолжают загружаться.

## AI-инструменты

OpenCode с моделью GPT-5.6 Sol использовался для проработки архитектуры, реализации интерфейса, тестов и браузерной проверки. Компоненты с 21st.dev использовались как визуальные референсы для композиции dashboard, sticky-стека и механики раскрытия объекта. Финальная реализация адаптирована под данные todo-приложения и проверена unit- и browser-тестами.
