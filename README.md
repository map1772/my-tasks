# Мои задачи

Адаптивный список задач в ретро-стилистике. Интерфейс собран по визуальному референсу и работает без сервера: данные сохраняются в браузере пользователя.

**Рабочий сайт:** [my-tasks-map1772.vercel.app](https://my-tasks-map1772.vercel.app)

**Исходный код:** [github.com/map1772/my-tasks](https://github.com/map1772/my-tasks)

## Возможности

- добавление задачи кнопкой или клавишей Enter;
- отметка выполненных задач;
- удаление отдельных задач;
- автоматический расчёт прогресса;
- сохранение в `localStorage` после каждого изменения;
- полноценная версия для компьютера и мобильных экранов;
- доступное управление с клавиатуры.

## Стек

- React 19;
- TypeScript;
- Vite;
- Vitest и React Testing Library;
- CSS без UI-фреймворков.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm run lint
npm run test
npm run build
```

## Хранение данных

Задачи хранятся в `localStorage` под ключом `my-tasks:v1`. Бэкенд, регистрация и передача пользовательских данных на сервер не используются.

## AI-инструменты

При разработке использовался OpenCode с моделью GPT-5.6 Sol: для планирования архитектуры, реализации интерфейса, тестов, проверки адаптивности и подготовки документации. Итоговая функциональность и production-сборка проверены отдельно.
